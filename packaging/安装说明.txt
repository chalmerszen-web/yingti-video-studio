映替 · 视频工作台 2.2.9（Windows x64 开发调试版）

1. 双击安装包，按中文安装向导完成安装。无需管理员权限。
2. 双击桌面上的“映替视频工作台”，直接进入独立应用窗口，无需打开浏览器。
3. 首次使用请自行导入 VocalignTech KEY。安装包不包含任何现有账号、KEY、视频、项目或成片。
4. 导入原片 → Omni-Analysis 分析 → 按资产导入替换图/音色或整篇台词 → WAN 生成。

已包含桌面界面运行组件、Node.js、FFmpeg、FFprobe 和本地涂抹修复运行包，无需另装 Python 或 CUDA。云端分析和生成仍需要联网，并按你的平台账户计费。

系统：64 位 Windows 10 / Windows 11。建议至少预留 3 GB 安装和临时空间，项目视频另需空间。

程序默认安装到：
%LOCALAPPDATA%\Programs\YingTiStudio

安装版项目、成片、日志和可选加密 KEY 默认保存在：
%LOCALAPPDATA%\YingTiStudio\data

直接从桌面图标进入即可，应用会在内部管理本地服务。重复打开会恢复同一个窗口，不会产生多个后台。

退出与升级：
- 最小化或关闭窗口会收起到系统托盘，后台任务继续运行。
- 点击右下角托盘中的映替图标可恢复窗口；图标可能位于托盘的折叠区域。
- 要完全退出，请右键托盘图标选择“退出映替”，或使用界面底部“退出应用”。
- 安装新版时会识别旧安装位置，自动保存进度、退出旧版并覆盖更新，无需先卸载；旧版运行中也可以直接安装。
- 本版可修复已确认属于映替的不完整安装，包括原目录只剩相同运行组件的情况；无需先删除目录。空文件夹也可以直接安装。
- 如果有素材正在导入，或平台提交正在保存任务 ID，安装程序会等待安全退出。若界面无法保存，安装会停止并保留旧版本，按提示处理后重试。
- 更新前会备份本地任务数据库，已保存项目、KEY、素材和成片继续保留。
- 卸载只移除程序，保留项目和视频数据；重新安装后可继续使用。
- 此安装版的数据与当前开发目录中的 data 分开，不会自动导入原有项目。

功能提示：
- 本次重点修复台词、商品漏换和面霜涂抹。整篇新台词的视觉参考不携带原人声；确认稿件、重点词和商品关联冻结到新版本，旧任务及原成片不重写。
- 画外口播新增独立配音：只选择当前账户已有且就绪的私有音色，不自动创建或克隆音色；也可导入已核对的整篇录音。有明确说话口型时选择画内对白并检查同步。独立模式使用完整新录音，不自动分离并保留原背景音乐或环境声。
- 真实配音比成片长时保留完整录音并停止后续视频提交，不截断正文、不自动加速；调整稿件或所选语速后另建版本。相同稿件、音色与语速的已保存配音可在本地复用；提交结果未知时不自动重复付费。
- 旧字幕可清理并制作新字幕、只清理、或保留。旧字幕和促销贴字的清理由 WAN 视觉编辑执行，新字幕由软件依据确认正文制作。文字正文精确，时间分配仍需预览；旧品牌、旧价格与底部小字的清理效果须逐项核对。
- 商品组可明确关联同款瓶罐、包装及容器内部商品；全部可见实例共享各自对应参考，分镜漏记不静默丢图。未上传容器图时只保留袋壳、提手及遮挡，已指定内部商品仍替换。无图成员保持原样，不自动套用另一成员参考；超过 10 张图片时先报错，不删参考后提交。
- 涂抹识别区分新增点涂与推开已有膏体。分类与证据冲突时停止自动加入相反要求，可人工核对后确认推开 / 揉匀；结束推匀为明确编辑选择。连续约束接触、覆盖面积、厚薄变化及同人物同部位状态，不让厚膏块随脸滑动，不从闭盖包装推断膏体或凭空制造吸收功效。
- 内容检查现在包含构图、接头、涂抹、实际台词、字幕、商品实例六类。独立听辨与冻结全文比较，价格、数量和品牌逐项核对；缺少声音、参考或完整观察不能判定通过。技术完成、未检查、需复核和发现问题分别显示，仍需人工验收，不自动重做。
- 瓶罐、包装盒、膏体分别分类并确认上传内容；已确认错配在提交前拦截。膏体默认使用动作模式，不把整罐或盒子作为脸部膏体几何参考。材质取样、颜色质地和同一目标人物的薄匀参考分别冻结到任务。
- 已有成片可进行本地局部涂抹修复，需核对真实动作、切镜、手部与长甲保护及目标人物自身肤质。该工具为手工校准，不是所有新项目的必经步骤；另存版本并沿用父版本完整声音，不回填原片旧对白。
- 本地修复独立于云端队列，不要求 KEY、不触发平台调用。云端动作重建支持首尾两帧或分部位四帧，按确认的请求收费；Omni-Analysis 可作为重建后的可选复核模型，没有因名称不同而默认认为更准确。
- 运行成功及模型检查结果不能代替连续视频的实际效果验收。未完成、遮挡无法判断和需要校准的结果保留状态，不自动提交收费重做。
- 新增片尾时间容错：台词和分镜的结束时间少量超出视频末尾时，可在时长比例限制内校正回真实片尾，最多容错 1 秒。原始结果、完整台词和校正记录保留，并提示复核。
- 已保存的分析结果遇到上述片尾误差，可点击“重新整理已保存结果”免费恢复，无需重新调用分析。完全在视频外、时间倒置、大幅越界和动作时间仍严格校验。
- 新增“动作与衔接”：只对明确识别到的点涂、推开和涂后残留增加对应时段约束；没有涂抹时不添加。旧项目请在该页点击“补充动作分析”（使用 Omni-Analysis 用量）。
- 先按原片镜头和动作规划 <=15 秒片段，再自动分配完整台词，尽量减少连续动作中途的接头。没有合适切点时提示风险，仍保留完整时间轴。
- “生成后检查画面”默认开启，会另外使用 Omni-Analysis 对照原片与成片及目标商品参考，调用数量在生成前显示；可取消勾选。检查素材只保留生成片声音，用于实际听辨。检查提供问题定位，仍需人工验收，不自动扣费重做。
- 生成记录提供“检查 / 重做”，可播放左原片/右新片对照。点击“只重做此段”另存新版本，仅重新生成所选段，其他段原样复用；完成后另用 Omni-Analysis 复查全部接头。
- 局部重做沿用所选旧版本的冻结素材、台词和分段。若要使用编辑页新上传的素材，请“再生成一版”。旧成片、任务和原始检查结果保留。
- 人物只有主视图时默认仅换脸，保留原片服装、发型、配饰和身形。
- 人物三视图或主视图＋三视图的合成图，可单独上传到“三视图 / 四联图”栏，直接替换整体造型，无需另补主图。
- 三视图请使用同一人物、同一套造型；支持 1 张合图，或正面、侧面、背面 3 张图片。移除三视图后，有主图则恢复仅换脸，没有任何人物图则保持原样。
- 上述规则仅影响之后新生成的版本，已提交任务和原成片不改变。
- 场景和产品未上传替换主图时保持原样；人物以已上传的主图或三视图/四联图决定编辑范围。
- 产品主体、包装和画面贴纸是不同对象，请把图片放在对应卡片。
- 全文台词可直接粘贴；多人对话可用“人物名：台词”。
- 所有新 WAN 请求开启提示词扩写，并保存实际请求设置。旧任务与原成片不自动重新生成。
- 采用 Flova 技能的全局锁定、固定台词、说话人/口型及声音三层约束，保留原片镜头与剧情；人物合图的白底和排版不进入视频。
- 新台词超过约每秒 6 个发声字/单位时，只显示语速风险提示，仍可继续生成；此数值是软件参考值，不是平台硬限制。全文不自动删改，不会因语速估计禁用按钮。
- 优先自然语速及完整句子；必要时按当前原片时长分配全文，在句末、标点或词语边界分段。部分台词可能跨原片切镜，生成后请预听语速与口型。跨镜头续接同一句时不从句首重复朗读。
- 发音说明可填写品牌名、字母或特殊词的读法，只约束发音，不改台词正文。分镜分析、语速估计和实际朗读效果仍需预览核对。
- 本版包含产品对应与动作冲突修正；模型的实际换人、换产品、声线与口型仍需人工预览验收。
- Omni-Analysis 返回少量缺引号、尾随逗号等明确格式错误时，会在本地修复并保留原始结果，不额外调用模型；不能安全修复或内容不完整时仍会提示处理。

故障排查：
启动失败时查看数据目录中的 launcher-error.log、desktop-error.log 和 server-error.log。更新未完成时查看 update-error.log。不要公开其中的私人文件名或项目内容。
若安装目录包含无法识别的其他文件，安装按钮会不可点击；请选择空文件夹或原映替目录，不要删除项目数据。

构建说明：本地测试安装包尚未做发布者数字签名。组件许可及来源位于 licenses 文件夹，FFmpeg 对应主源码包位于 third-party-sources 文件夹。
