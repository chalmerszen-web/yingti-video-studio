# 映替 · 视频工作台

Windows 本地视频编辑工作台：Omni-Analysis 分析原片，编辑人物、场景、产品与整篇台词，再使用 WAN 3.0 生成新版本。

当前源码基线：**开发版 2.2.9 / 用户版 2.3.6**。软件版本发布于 2026-10-14，本公开源码快照整理于 2026-10-24。

**Agent 接手入口：[AGENT_HANDOFF.md](AGENT_HANDOFF.md)**；仓库工作约定：[AGENTS.md](AGENTS.md)。

## 功能

- 人物主图、三视图/四联图、场景、产品和参考音色导入；支持拖放素材。
- 完整台词替换、独立配音与字幕处理；冻结每次生成使用的素材和正文。
- 产品主体、包装、容器与膏体材质分别分类，避免将包装外观当作膏体质地。
- 所有新分析/检查请求使用 Omni-Analysis；历史 Omni-Plus 元数据只用于兼容读取。
- 默认生成等待期限 3600 秒，支持主动中止、保留已有片段、预览及合并/单片导出。
- 恢复查询复用已有任务编号；提交结果未知时不自动重复付费提交。
- 本地 CPU 材质修复与逐帧校准，保留原音轨及受保护区域。它需要人工校准和视觉复验，不保证任意素材一键修复。
- 用户版与开发版独立安装、独立数据目录；默认只监听本机。

**余额预检目前明确停用**，等待平台提供新的余额/费率接口。不要将无限额度占位值当作钱包余额，也不要把跳过检查表示为足额。

## 从源码运行

目标环境：Windows 10/11 x64、Node.js 24+、FFmpeg 和 FFprobe。确保命令在 PATH 中可用，或设置 FFMPEG_PATH / FFPROBE_PATH。

```powershell
npm ci
npm run check
npm test
npm start
```

浏览器打开 http://127.0.0.1:3210 。在界面导入自己的 VocalignTech KEY；需有对应模型权限。云端分析、配音和视频生成可能产生平台费用。测试使用模拟服务，不需要真实 KEY。

可设置 WAN_EDITOR_PORT、WAN_EDITOR_DATA_DIR。默认开发数据目录为 data/；不要把含密钥或客户素材的数据提交到 GitHub。KEY 不从全局环境变量读取，可选由 Windows 账户加密保存。

没有准备本地 Python/模型运行包时，本地材质修复不可用，其他能力由其各自依赖决定。见 [构建与运行](docs/BUILD.md)。

## 源码结构

| --- | --- |

| public/ | 原生 JavaScript/CSS 用户版与开发版界面 |
| desktop/ | Electron 桌面壳、托盘与实例生命周期 |
| worker/local_material/ | Python CPU 材质处理及测试 |
| test/ | Node 自动化测试与模拟服务 |

| scripts/ | 启动、构建、更新和数据备份 |
